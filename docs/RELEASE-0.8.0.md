# Pulse VPN 0.8.0

## Интерфейс

- Один экран настроек вместо двух: все 38 параметров и действий доступны в семи разделах.
- Общий поиск по названиям, подсказкам и вариантам выбора.
- Быстрый доступ к режиму VPN и DNS сразу под поиском.
- Разделы раскрываются на месте; найденные параметры раскрываются автоматически.
- Темы представлены компактной горизонтальной галереей внутри «Оформления».
- Для сетевых параметров доступны полные пояснения по кнопке информации.
- Главная стала плотнее; вместо слогана показываются режим маршрутизации и DNS.
- Выбранный маршрут показывает протокол.
- Сворачивание подписки больше не скрывает список серверов на главной.
- Старый скрытый экран дополнительных настроек удалён; история доступна в Git.

## Исправления

- Неудачный импорт не закрывает форму и не теряет введённый текст.
- Ввод, вставка, QR и закрытие заблокированы на время импорта.
- Проверку пинга можно отменить кнопкой «Отмена» на экране маршрутов.
- Обновление/смена подписки останавливает предыдущую проверку.
- Старые результаты не заменяют серверы обновлённой подписки.
- Очистка истории отменяет текущую проверку перед удалением замеров.
- Отменённая проверка не сбрасывает состояние более новой проверки.
- Повторные нажатия переподключения не запускают параллельные операции.
- Конфигурация и метаданные сохраняются через временный файл и атомарную замену, когда файловая система её поддерживает.
- Генерация эффективной конфигурации синхронизирована в репозитории.
- Временный файл удаляется после успешной или неудачной записи.

## Проверки

Unit-тесты, Android lint, проверка конфигураций libbox и сценарий Android-эмулятора.
Дополнительно проверяются сохранение ошибочного ввода, поиск обычных/расширенных настроек,
доступ к DNS с основного экрана, темы, небольшой экран и системный шрифт 150%.
Проверка записи покрывает UTF-8, замену, неудачную замену и параллельные записи.
Эти проверки не заменяют подключение реальной подписки на телефоне.

Подпись release не меняется: APK совместим по ключу с 0.7.0, versionCode увеличен до 47.
HEX и платные операции не добавлялись. Ссылки подписок и ключи не логируются.
